
# TecnoGestión

## Descripción del proyecto

TecnoGestión es una empresa ficticia dedicada al desarrollo de soluciones de software para pequeñas y medianas empresas (PyMEs).

Este repositorio documenta la planificación y el diseño de un módulo de Gestión de Proyectos y Clientes, orientado a centralizar la información de clientes, proyectos, requerimientos, tareas, responsables, fechas de entrega y estados de avance.

## Objetivo general

Desarrollar e implementar un módulo que integre los procesos de las áreas Comercial, Análisis, Desarrollo, Testing, Soporte y Administración, mejorando el seguimiento de los proyectos, la trazabilidad de las tareas y la consistencia de la información.

## Alcance funcional

- Registrar clientes y sus proyectos asociados.
- Documentar requerimientos y tareas.
- Asignar responsables, prioridades y fechas.
- Consultar estados y avances de los proyectos.
- Facilitar el intercambio de información entre las áreas.
- Registrar incidencias y oportunidades de mejora.

## Objetivos técnicos

- Alcanzar un tiempo de respuesta inferior a 1,5 segundos para el 95 % de las peticiones contempladas en las pruebas.
- Diseñar una solución que soporte al menos 500 proyectos activos y 10.000 tareas asociadas.
- Establecer como objetivo una disponibilidad del 99,5 % durante el horario laboral.
- Planificar la implementación dentro de las 16 semanas previstas.

Estos valores son objetivos del proyecto y deberán verificarse mediante pruebas y mediciones.

## Organización del trabajo

El proyecto se documentará mediante:

- Modelado de procesos con notación BPMN.
- Control de versiones con Git y GitHub.
- Ramas de trabajo, commits descriptivos y Pull Requests.
- Historias de usuario y seguimiento mediante un tablero ágil.
- Indicadores de control técnico y organizacional.
